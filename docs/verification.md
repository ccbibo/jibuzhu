最初發佈快照為 373 項、372 通過、1 項略過；其中 S10 實際上是固定跳過的空白人工驗收占位，先前稱「條件式」不準確。使用者於 2026-11-01 明確確認真人驗收通過後，已移除這個空白占位，改為獨立的 [S10 人工驗收紀錄](acceptance/notion-owner.md)。目前自動化回歸為 **379 項，379 通過，0 略過，0 失敗**，另列 **1 項人工驗收通過**；沒有把本人聲明冒充成這次重新執行的真實 API 測試。發佈快照會在隔離目錄重新執行全套，確保必要來源與測試未被包裝過程遺漏。

本輪新增七項回歸，重現後修正：

- 條件更新後，舊問答的晚到錯誤不能覆蓋新狀態。
- 舊 409 回應、以及其設定重查的晚到結果，不能清掉新答案。
- 個人資料網路儲存未完成時，換頭像不能解除儲存鎖或併發寫入。
- 人物改顯示名後，AI 請求仍使用原文標記與完整會議，不能把別名當身分證明。
- 問答停止、關閉或換會議後，不採用過期結果；供應商變更須重新同意。

既有覆蓋包括 salted scrypt、session 雜湊、登出撤銷、設定管理權限、帳號隔離、同分頁工作恢復、來源驗證、長文分塊、引用驗證與 Notion 讀回／防重。

## 發佈邊界

只發佈本機產品必要程式、測試、公開素材、啟動說明與這份去識別化紀錄。原本機 Git 歷史含私人 Notion 驗收連結，改以乾淨快照建立 GitHub 歷史；不將原始歷史推送，不包含帳號、私人逐字稿、密碼或 API 金鑰。

## GitHub 全內容複審修正

本輪以遠端快照核對說明、展示入口、資產、檔案清單與完整測試。修正切換登入帳號後舊分頁可能沿用草稿送出的風險：寫入附帶目前帳號識別，帳號改變即拒絕並鎖定舊分頁；另以實際前端腳本與隔離 HTTP 處理器交叉驗證。期限文字必須能在引用原文找到，否則清除或回復原文期限。
