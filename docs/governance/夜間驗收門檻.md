# 記補住：交付評分門檻 v1

2026-10-31。開始新一輪實作前凍結，不能為取得通過調低門檻。十名agent是十個獨立上下文的模擬測試角色，不是真人或不同模型的品質保證。兩批各五人，獨立執行後交換反例；主agent仲裁，修正需重測。

## 分數

每位依其分派任務提交原始重現步驟、實際結果、缺陷嚴重度與0–100分。每人採相同五項：任務可完成30、來源與內容正確30、錯誤與資料保護20、可理解與可操作10、證據與文件10。不得評未做的測試為通過；未測標N/A並說明，總分只代表分派情境。

本機可測候選版門檻：十位都至少90分、總平均至少92分，無未解P0（資料外洩、破壞或核心造假）/P1（錯人物、虛假來源、誤稱同步成功、無法完成主線）缺陷；全套回歸零失敗。較低分保留，修正後由原測試者重評，不能換人洗分。主agent另評完整交付度，不用測試平均取代產品完成。

## 硬性完成門

完整產品必須另有：真實AI語意問答品質驗收（非mock）、本人指定Notion由本程式寫入後完整讀回來源與欄位、防重再提交、實際瀏覽器桌面與手機操作、本地可重現啟動、版本與限制說明。缺憑證、無API連線或工具受阻時只能標「候選版／等待本人接續」，不能假裝達到完整成品。GitHub仍等使用者醒來確認成品後才上傳。

## 語意 API 契約

POST /api/ask body {meeting:MeetingInput, question:string(1–1000trim), speaker:string(0–80trim)}。沿用local session、same-origin、body限制和每分鐘5次AI速率限制，與extract共用。無key回503不偷換demo；未授權不呼叫provider。

response {mode:'ai',meetingId,question,speaker,claims:[{text:string,kind:'viewpoint'|'proposal'|'objection'|'revision'|'decision'|'unknown',citations:[{lineIndex:number,quote:string,speaker:string|null}]}],caveats:string[],notice:string}。全部原文傳模型，最多12claims每項1–4引用，引用必須為該0-based行的非空逐字片段；speaker由來源解析，不能相信模型提供。若指定speaker，每項claim至少有一引文屬該speaker。任何失效引文使整體拒絕，不只丟掉錯誤部分。summary文字／kind仍是模型判斷，需要使用者查證；精確引文校驗不等於語意蘊含驗證。無足夠依據允許claims空陣列；不能把沉默/最後發言當共同決議。

Frontend顯示詞彙/AI明確區隔；key未配置時有說明。AI需按按鈕才送全文，不在載入或切換時傳。所有引用可跳回原文，動態文字安全渲染；修改來源或問題清除結果、忽略過期回應。原文仍不持久化。引用分組呈現觀點、異議、修正，保留不確定性。可匯出問答與引文至本機JSON/Markdown。

## Notion讀回補強契約

POST /api/verify body 與sync相同 {meeting,meetingId,tasks,approved:true}。僅讀取，不claim、不create；按sourceId定位頁面，讀properties與paginated block children，對照當前審閱的title/owner/date/priority（若有該欄）、來源ID、evidence、會議/行號。response {results:[{taskId,status:'verified'|'mismatch'|'missing'|'failed',url?,differences:string[],message?}]}。重複sourceId必須mismatch，不拿第一個冒充核對成功。讀回失敗不重寫。完整readback不可由created/existing收據代替。


## 審查新增的輸出防誤用門（保留原契約）
